# 英検準2級プラス 単語4択問題集

英検準2級プラスの大問1「短文の語句空所補充」の形式で、単語問題を10問ランダム出題し、1問ごとに正解・訳・解説を表示して100点満点で採点するブラウザ問題集です。スマホのホーム画面に追加するとアプリのように使えます（PWA）。

公開URL: https://masatopapa.github.io/eiken-quiz/

- 問題はすべてオリジナルです（公式の過去問・サンプル問題の転載ではありません）。
- 訳・解説はAIが作成したものです。意味や用法は辞書・教科書で確認してください。
- 更新はネット優先のService Workerで自動配信されます（次に開いたときに新版になります）。
